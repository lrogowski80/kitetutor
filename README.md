# KiteTutor – podgląd portalu

Statyczna wersja demonstracyjna portalu KiteTutor (10 ekranów: strona główna, rejestracja, wyszukiwarka korepetytorów, profil i rezerwacja, płatność, panel ucznia, pokój lekcyjny, album Ekipy, panel korepetytora, panel rodzica).

Dane, ceny, profile i opinie są przykładowe. Strona jest indeksowana przez wyszukiwarki i hostowana przez GitHub Pages pod adresem https://kitetutor.com.
